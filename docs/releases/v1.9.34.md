# wb2api v1.9.34

修复工具历史消息导致的 11101，增加 HTTP/2 断流后的临时协议降级，并同步上游兼容更新。管理面板保留七个视图、明暗主题和原有操作，重新整理卡片、表头、工具栏与窄屏布局。

## 断流与错误处理

- assistant 的 `tool_use` 和 user 的 `tool_result` 转为 OpenAI 工具历史格式，再执行配对清理。保留正文和工具参数，不替换 `11128` 或 `111-28`。
- 已成功建立的 HTTP/2 响应发生 `INTERNAL_ERROR`、`PROTOCOL_ERROR` 或非正常 EOF 时，该上游的后续聊天请求临时改用 HTTP/1.1，5 分钟后重新尝试 HTTP/2。不会重放已经输出的半截回复，也不因该传输错误惩罚账号。
- HTTP 503 的腾讯云 WAF HTML 页面进入既有 WAF 处理，保留原文与 Request UUID。这个改动修正分类，不能解除上游防火墙的实际拦截。
- 11102 和候选范围内的模型锁定返回 `400 model_unavailable`，说明需换模型；6004 模型限流仍保留本分支的 `429 + Retry-After`。
- 请求日志区分 HTTP 成功与流正常完成，记录请求 ID、结果、耗时、尝试次数、Token 和积分。

上游 [issue #81](https://github.com/linguo2625469/workbuddy2api-panel/issues/81) 最后的定位是客户端截短工具调用 ID，导致并行调用 ID 碰撞。v1.9.33 已有工具 ID 去重；它不能单独解释 HTTP/2 断流或 `unsupported content type: tool_use`。

## 面板变化

- 统一卡片间距、表格留白和按钮高度，长说明独立换行；手机上导航横向滚动、卡片两列排列，宽表格在容器内滚动。
- 模型页保留国内版/国际版切换，增加关键词、能力、思考档位、价格筛选，以及倍率/上下文/输出长度排序。
- 运行日志新增请求结果与时间筛选；可搜索模型、账号、请求 ID、IP 和客户端。归档空区间显示空结果，不回退成范围外的内存记录。
- 用量可查看全部保留历史或自定义区间；原有缓存命中率与按账号/模型/域统计保留。

## 升级

容器使用 `ghcr.io/csszyf/wb2api:v1.9.34`；也可下载 Release 中对应系统的压缩包。保留原有配置、账号凭证和数据目录，升级后重启服务使新代码生效。

请求归档默认开启，保留 7 天、容量上限 100 MiB。`logging.request_client_info` 默认记录 IP / User-Agent，可在面板关闭并立即生效；归档开关、保留天数与容量需重启。

本次没有替换正在运行的本地服务。协议降级降低特定 HTTP/2 故障的后续影响，不能保证上游永不掉线；已经断开的回复仍需客户端重新发起。
