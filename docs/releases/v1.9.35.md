# wb2api v1.9.35

修正上游错误契约：`11133` 参数拒绝不再伪装成 `503 all accounts unavailable`，WAF 拦截页不再整页灌进错误文本；账号池新增「快过期积分优先消费」与「日均需耗 / 今日已耗」两个概览数字。

## 错误契约与日志

- `11133 model_param_invalid` 改回 `400 bad_params` + 上游原文：同一请求在两个不同账号上拿到同一业务码即证明请求级终态（确定性收敛，最多打 2 次上游，不再放大到满轮转）；轮转耗尽后末端同口径 400 透传。此前 503 会让 OpenAI 兼容客户端把必败请求当可重试故障反复打。`11101`、不罚号、首个 11133 仍换号的语义不变。
- HTML 错误页（腾讯云 WAF Block Page 等）统一压成单行摘要：`HTML error page: WAF Block Page (WAF request uuid: …)`——Request UUID 保留可提交 WAF 误杀反馈。JSON 业务错误继续逐字透传，作用于客户端 `error.message`、面板日志与上游日志三处。
- 失败请求出口新增 `chat_stream model=…: terminal <status> <code>: <msg>` 日志行：此前客户端看到的 4xx/5xx 终态在面板运行日志里完全不可见（只有逐次尝试行），现在面板 sys 频道能与上游客户端（如 newapi）侧记录对上。

## 账号池与选号

- 顺序模式优先消耗 **168h 内快过期积分**的账号，按最近到期排序（FEFO）；其余账号保持拖动顺序，占满正常溢出。`reserve_credits` 仍是资格闸门：贵模型只选余额 >50 的账号，免费模型不受限；快过期到期时刻持久化进 `state.json`，重启不丢排序。
- 概览条新增两格：**日均需耗**（各账号最近到期批次需耗之和，与到期提醒同口径）与**今日已耗**（上游实扣积分，弱显 token 数），达标染绿、未达琥珀。
- 账号池头部压缩为单行 KPI + 分组批量操作；模型锁池为空时整盒隐藏；积分到期提醒展开后完整显示不再内滚。
- `GET /` 302 到 `/panel/`，直连根路径自动进面板。

## 升级

容器与二进制均沿用既有发布通道（GHCR `ghcr.io/csszyf/wb2api:v1.9.35` / `latest`，Release 五平台包）。无配置迁移；`state.json` 自动补写 `credits_expiring_at` 字段。
