# wb2api v1.9.36

新增国际服 DeepSeek 免费额度耗尽后的 SG 回退，并同步参考上游至 `8461419`。保留 v1.9.35 的界面、到期优先 Fill First、裸模型名和国服/国际服分栏。

## 免费优先，耗尽后使用 SG

- 默认开启 `pool.deepseek_sg_fallback`，面板「配置 → 账号池」可开关，保存即时生效。
- 只适用于 `global:deepseek-v4.1-flash`，以及默认路由到 global 的裸名 `deepseek-v4.1-flash`。
- 所有未禁用、未临时停用的国际服候选账号都已有该免费模型的有效限流记录，才改用 `global:deepseek-v4.1-flash-sg`。
- 普通网络故障、WAF、模型不存在、并发占满、只有部分账号限流，不会触发自动付费。启用此策略的裸名请求固定国际服，不跨到国服。
- SG 只选择健康、并发未满、余额已知且严格高于 `pool.reserve_credits` 的账号；不会因目录将 SG 标为低价而绕过保留线。余额未知时不自动花费，先在面板刷新余额。
- 每个新请求重新检查免费池；冷却到期、探活成功或手动恢复使免费模型可选后，优先免费，不会被 SG 的会话粘性锁住。正在进行的 SG 回复正常完成。
- SG 成功请求按实际 SG 模型记录 Token 和积分；响应头 `X-WB2API-Actual-Model` 标识实际模型。上游返回的实测积分会立即更新本地余额。
- 免费与 SG 各有一个有界轮转阶段，均受 `server.max_rotate` 约束；最后一个免费尝试才确认全池耗尽时，同一请求仍可进入 SG 阶段。

保留积分是在选号时检查的余额门槛，不是上游的硬预算锁。单次回复最终扣费和同时在途的请求可能使结算余额低于门槛；建议开启余额定时刷新，并按需求设置单号并发。已向客户端输出的流不会重放：如果免费限流以流内 error 帧返回，该次请求正常返回错误，后续请求按更新后的池状态回退。
